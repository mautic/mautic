# Filtro rápido para empresas sem proprietário

Na lista de empresas, o menu de filtros rápidos agora oferece `Unowned companies`.
Ele usa o comando existente de busca `is:unowned` para mostrar empresas cujo proprietário está vazio, sem alterar nenhum registro.

Antes, era preciso abrir os filtros, lembrar ou digitar `is:unowned` e aplicar a busca (3 ações). Agora, com a lista aberta, basta abrir os filtros rápidos e escolher `Unowned companies` (1 ação para a decisão), reduzindo o caminho repetido em dois terços.

Para validar, abra Companies, abra Quick filters e escolha Unowned companies. A lista deve mostrar apenas empresas sem proprietário; limpar a busca retorna à lista normal.
