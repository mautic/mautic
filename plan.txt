Migration Plan: Move OpenIdBundle into UserBundle for Mautic 7/Symfony 7
Overview
Migrate the custom OpenIdBundle OIDC implementation into UserBundle under Security/OIDC/, following the existing Security/SAML/ pattern. This consolidates all backend user authentication (local, SAML, OIDC) in one place.

Prerequisites
The jumbojett/openid-connect-php dependency should already be in composer.json
Familiarity with Symfony 7 security system changes (authenticators replace guards)

Phase 3: Create Symfony 7 Authenticator
Create UserBundle/Security/OIDC/OidcAuthenticator.php implementing Symfony\Component\Security\Http\Authenticator\AuthenticatorInterface.

Replace the old guard/firewall approach with Symfony 7's authenticator system:


<?php

namespace Mautic\UserBundle\Security\OIDC;

use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Security\Core\Authentication\Token\TokenInterface;
use Symfony\Component\Security\Core\Exception\AuthenticationException;
use Symfony\Component\Security\Http\Authenticator\AbstractAuthenticator;
use Symfony\Component\Security\Http\Authenticator\Passport\Passport;
use Symfony\Component\Security\Http\Authenticator\Passport\Badge\UserBadge;
use Symfony\Component\Security\Http\Authenticator\Passport\SelfValidatingPassport;

class OidcAuthenticator extends AbstractAuthenticator
{
    public function __construct(
        private readonly ClientInterface $client,
        private readonly Linker $linker,
        private readonly SettingsFactory $settingsFactory,
    ) {}

    public function supports(Request $request): ?bool
    {
        // Check if this is the OIDC callback route
        return $request->attributes->get('_route') === 'mautic_oidc_check';
    }

    public function authenticate(Request $request): Passport
    {
        // 1. Verify OIDC callback and get claims
        // 2. Use Linker to find or create user
        // 3. Return SelfValidatingPassport with UserBadge
    }

    public function onAuthenticationSuccess(Request $request, TokenInterface $token, string $firewallName): ?Response
    {
        // Redirect to dashboard or intended URL
    }

    public function onAuthenticationFailure(Request $request, AuthenticationException $exception): ?Response
    {
        // Redirect to login with error
    }
}

Key Symfony 7 Changes to Watch
SessionInterface - Get from RequestStack, not injected directly
Guards removed - Use AuthenticatorInterface instead
PasswordEncoder → PasswordHasher - If any password operations exist
Annotations → Attributes - Prefer PHP 8 attributes for routes, DI, etc.
Return types - Ensure all methods have proper return type declarations
